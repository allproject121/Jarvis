## 🌟 Key Capabilities

### 🧠 1. Dual-Brain AI & Voice Pipeline
- **Cloud Intelligence:** Persistent bidirectional audio streaming via Google Gemini Live & OpenAI GPT-4o with real-time tool dispatch.
- **100% Offline Edge Brain:** Local quantized models (Gemma 2, Qwen 2.5, Llama 3.2) via embedded `llama.cpp` runtime with zero internet needed.
- **Continuous Voice Loop:** Vosk on-device wake-word detection, speaker verification, and low-latency speech synthesis.

### 🛰️ 2. God's Eye View (Geospatial Reconnaissance)
- **3D Cesium Globe:** Photorealistic planetary rendering with terrain and satellite imagery.
- **Live Telemetry:** Real-time AISStream maritime vessels, OpenSky flights, FIRMS wildfire thermal hotspots, USGS earthquakes, and 3,700+ CCTV camera streams.

### 🎭 3. Holographic 3D Companions & Studio
- **Dynamic 3D Visualizer:** Audio-reactive 3D Arc Reactor, Quantum Orb, and customizable VRM companion characters (Mora / J.E.T.T.).
- **Floating HUD:** System-wide overlay companion dockable to screen edges with minimal battery footprint.

### 📱 4. Jarvis SuperCore OS Automation
- **Autonomous Navigation:** Deep Android accessibility automation for hands-free typing, app launching, and system settings control.
- **Smart Messaging:** Automated hands-free WhatsApp and messaging workflows.

### 🛡️ 5. Guardian Security & Anti-Theft Sentry
- **Touch Guard & Intruder Capture:** Motion sensors trigger alarms and capture camera snapshots on unauthorized handling.
- **Hardware-Backed Security:** API credentials encrypted via Android Keystore (AES-256 GCM).

## 🛠️ Build & Development

### Method 1: Cloud Build (GitHub Actions)
Every push to `main` automatically compiles, verifies, and packages the debug APK via GitHub Actions. Download the latest builds directly from [GitHub Actions Artifacts](https://github.com/allproject121/Jarvis/actions/workflows/build-apk.yml) or [GitHub Releases](https://github.com/allproject121/Jarvis/releases).

### Method 2: Local Compilation
- **Requirements:** JDK 17, Android Studio 2024.1+, Android SDK (API 28–35).

```bash
# Clone the repository
git clone https://github.com/allproject121/Jarvis.git
cd Jarvis

# Build Debug APK
./gradlew :app:assembleDebug
```
The output APK is generated at `app/build/outputs/apk/debug/app-debug.apk`.

## ⚙️ App Configuration

1. Launch JARVIS on Android.
2. Open **Settings (⚙️) > Neural Brain & Connections**.
3. Add your keys:
   - **Gemini API Key:** From [Google AI Studio](https://aistudio.google.com/) (for cloud voice streaming).
   - **Cesium Ion Token (Optional):** For 3D photorealistic globe tiles in God's Eye.
